Project: Automated Contract Review — Project Page Template

Summary

Timeline: Apr 2024 — Jul 2024 • Team: PM, 2x DS, 3x Eng • Outcome: 60% review time reduction in pilot

Problem & Context

Manual contract review took 3–10 days. High variability and missed terms impacted renewals.

Goals & Success Metrics

  • Reduce average review time by 50% within pilot
  • Precision@k for clause extraction ≥ 0.85
  • Reviewer adoption ≥ 40% in pilot accounts

Approach

Data pipeline: ingestion → labeler → model training (transformers) → inference API → reviewer UI. Iterative AB test on reviewer UI changes.

Deliverables

  • PRD (Doc)
  • Architecture diagram (Slide)
  • Project Folder (Drive)
  • Demo video (YouTube)

Outcomes

60% reduction in review time; 3.9x reviewer throughput for labelled clauses. Business impact: reduced legal costs, faster deal cycles.

Key learnings

  • Precision matters more than recall for reviewer acceptance.
  • UX for triage drastically affects adoption.
